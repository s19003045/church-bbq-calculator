# New × 敬傑小組｜聯合烤肉採買計算器

活動：2026/10/31（六），15:30–17:30 預備、17:30 開始烤肉。

## 功能

- 調整大人、小孩人數、孩童食量與整體食量
- 自動試算 A 肉品、B 蔬菜海鮮、C 主食甜點、D 飲料水果、E 器材餐具組採買數量
- 牛、豬、雞 1:1:1，顯示公斤與臺斤（1 臺斤 = 0.6 公斤）
- 每組顯示細項與採買說明
- 個人瀏覽器可記錄認領人、實際費用及完成狀態
- 可複製 LINE 採買總表、產生參數分享連結及匯出 JSON

## GitHub Pages 啟用

## 重要限制

本專案是純靜態網頁，**沒有共用資料庫**。認領人、金額、完成勾選存在各自的瀏覽器 localStorage，不會即時同步給其他人；分享連結只同步人數與食量參數。各組應以統籌發布的 LINE 採買總表為準。

數量為避免剩食的保守起始估算，依實際參加人數、喜好及過去剩食情況修正。
